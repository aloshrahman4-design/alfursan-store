# alfursan-mods: إضافة Claude Code لمتجر الفرسان

ثلاث أفكار من فيديو "Claude Code Mods" بإضافة وحدة:

## 1) جلسات تتكلم وية بعض
- `/team الهدف`: يشغّل فريق من ثلاث وكلاء: **الباحث** يجمع المعلومات، **المسوّق** يكتب المنشورات ورسائل الواتساب، و**المدير** يرتب الأولويات ويسلمك الملخص. يتراسلون بينهم بـ SendMessage.
  مثال: `/team جهزلي حملة لمنتجات الشتاء الجديدة`
- `/send الاسم الرسالة`: يرسل رسالة لجلسة ثانية أو لوكيل.
- كل رسالة توصل تنحفظ بتبويب "الرسائل" باللوحة.

## 2) توفير الاستهلاك
- كل طلب يتصنّف تلقائياً بالكلمات، بدون ما يكلف أي طلب إضافي:
  - **Opus**: أمن، خلل، تصميم، تسعير، تحليل، أو طلب طويل.
  - **Haiku**: طلب قصير وبسيط.
  - **Sonnet**: الباقي.
- الوكلاء اللي شغلهم بحث وقراءة بس (Explore وغيرهم) يشتغلون على Haiku.
- `/saver on` أو `/saver off` يشغّل أو يطفي الميزة.
- ⚠️ تبديل الموديل بين طلب والثاني يخسّر ذاكرة الكاش، فلو أغلب شغلك من نفس النوع يفضّل تطفيها.

## 3) لوحة تحكم جنب المحادثة
- `/alfursan`: يفتح "لوحة الفرسان" بثلاث تبويبات: المهام، الرسائل، والموديل.
- `/task نص المهمة` يضيف مهمة، و`/task done 2` يعلّم المهمة 2 خالصة، و`/task clear` يمسح المهام الخالصة، و`/task` لوحده يعرضها كلها. تگدر تعلّم المهمة خالصة بالضغط عليها باللوحة. المهام تبقى محفوظة بين الجلسات.

## التثبيت
```
claude --plugin-dir mods/alfursan-mods
```
أو انسخ المجلد لمجلد الإضافات عندك. الفحص: `claude plugin validate mods/alfursan-mods`، والاختبارات: `claude plugin test mods/alfursan-mods`.
