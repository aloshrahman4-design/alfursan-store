# Customer text in Iraqi Arabic

- Dialect: Iraqi (شلونج، هواية، گدرتي، تحصلين), addressed to women (feminine: بيج، ضيفي، اطلبي).
- Short, warm, no formal Fusha. 1-3 emoji max, not on every line.
- Never invent specs, sizes, colours, prices or discounts: use only data the user gave. Prices in دينار عراقي, formatted with thousands separators.
- Include the shipping rule only when true: free shipping for orders of 3+ pieces.
- Order-tracking line, when relevant: the 4-character code + the status WhatsApp number from `index.html`.
- Give 2 variants (short / detailed) and let the user pick.
